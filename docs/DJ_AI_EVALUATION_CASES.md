# DJ AI Evaluation Cases

Regression coverage should include:

- Doubt clarification
- Coding
- SQL/DAX/Python
- Data analysis
- Multimodal grounding
- Web research provenance
- Tool correctness
- Memory/RAG grounding
- Security and privacy
- Provider failure/fallback
- Cost and latency

Each case should have an expected outcome and be evaluated before model/routing changes are promoted.
