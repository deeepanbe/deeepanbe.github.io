# DJ AI Model Routing

- **Auto:** select the best configured model for the task.
- **Fast:** favor low latency and low cost.
- **Deep:** use stronger reasoning when justified.
- **Compare:** obtain multiple independent answers and synthesize.
- **Fallback:** switch providers on recoverable provider failure.

Routing decisions should consider task type, modality, context size, quality requirements, latency, user plan, and budget.
