# DJ AI Self-Evaluation Dimensions

Every major capability should be evaluated on:

- Correctness
- Relevance
- Groundedness
- Clarity
- Completeness
- Safety
- Tool correctness
- Multimodal grounding
- Latency
- Estimated cost

A response should not be considered better merely because it is longer or more confident. The evaluator should prefer evidence, useful reasoning, and correct outcomes.
