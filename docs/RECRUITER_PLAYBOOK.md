## Interview questions this portfolio is designed to answer

- How did you define the business problem?
- What was the grain of the dataset?
- How did you validate the data?
- Why did you choose SQL, Python or Power BI?
- How were KPIs defined?
- What assumptions did you make?
- What did the analysis actually prove?
- What did it **not** prove?
- How would you productionize the workflow?
- What would you improve with more data?

## Accuracy standard

This portfolio deliberately avoids:

- fabricated business impact
- invented conversion/ROI figures
- unsupported employment claims
- calling RFM analysis machine learning
- presenting portfolio projects as commercial client work
