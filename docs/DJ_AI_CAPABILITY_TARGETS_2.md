# DJ AI Capability Targets

DJ AI should progressively support:

- Doubt clarification and tutoring
- Code generation, debugging and review
- SQL, DAX, Python and Excel
- PDF/DOCX/XLSX/CSV analysis
- Image understanding and image generation
- Web research with provenance
- Data analysis and visualization
- Multi-model comparison and synthesis
- Memory/RAG
- GitHub workflows
- Voice
- Browser automation with explicit permissions
- Android

Only expose capabilities that are actually configured and validated.
