## 🔬 My analytics quality gate

A project is not “done” because the chart renders.

Before calling an analysis complete, I ask:

- **What business decision does this support?**
- **What is the grain of the data?**
- **Can I explain every important KPI?**
- **Were duplicates, nulls, types and key integrity checked?**
- **Were source totals reconciled?**
- **Are the model relationships defensible?**
- **Can another analyst reproduce the result?**
- **Are limitations and assumptions visible?**
- **Am I separating correlation from causation?**
- **Have I avoided inventing metrics, impact or experience?**

This is the standard I use to turn a portfolio project into an interview conversation.

## 🧰 Engineering principles

- **Decision-first:** analytics exists to support action.
- **Traceable:** important metrics should be explainable.
- **Reproducible:** repeatable transformations beat manual magic.
- **Secure:** secrets stay server-side.
- **Modular:** AI providers sit behind adapters.
- **Tested:** critical backend behavior should be checked.
- **Honest:** limitations are part of the result.
- **Maintainable:** small, reviewable changes over fragile rewrites.
