# Component System Notes

The portfolio is built with static HTML, CSS, and JavaScript. Components are represented through reusable class patterns rather than a framework.

Core component families:

- Sticky navigation
- Hero KPI system
- Glass analytics panels
- Service cards
- Project case-study cards
- DJ AI drawer
- Private access modal
- Resume/contact panel
- Floating section navigation

CSS tokens live in `styles/platform.css`.
