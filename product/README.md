# DJ AI Product

DJ AI combines GitHub engineering automation and career intelligence.

## Primary product
An approval-gated AI software engineer that continuously analyzes authorized repositories, reviews changes, proposes fixes and prepares pull requests.

## SaaS model
Multi-user accounts, GitHub OAuth/App connection, repository-level authorization, usage-based plan limits and hosted billing.

## Launch rule
Production activation requires credentials/configuration listed in LAUNCH_CHECKLIST.md and passing staging/end-to-end tests.
