# DJ AI Public Beta

## Goal
Validate DJ AI with real users before investing in a large Android/mobile and advanced-agent release.

## Beta promise
DJ AI is a practical AI assistant for data, business, documents, coding and productivity. Beta users get the core experience free while the product is improved from feedback.

## Beta capabilities
- Verified customer accounts
- Secure AI chat
- Conversation history
- Basic personal memory
- Text document ingestion
- Private workspace knowledge
- RAG search
- Basic agent/tool execution
- SQL/Python/Power BI/Excel assistance
- Usage tracking
- Feedback collection

## Deliberately limited during beta
- No autonomous production code changes
- No unrestricted external actions
- No automatic model self-modification
- No promise of perfect factual accuracy
- No real-money billing until payment/security testing is complete

## Product learning loop

1. User asks a question.
2. DJ AI produces an answer.
3. User can mark useful/not useful and provide feedback.
4. Product team reviews failures and requests.
5. Prompts, retrieval, tools, evaluations and UI are improved.
6. Automated tests are added for important regressions.
7. New version is released.

## First target
Recruit 10–20 trusted beta testers. Do not publicly advertise the service until the production backend, database isolation, email verification, Turnstile, monitoring and spending controls have been tested.

## Success metrics
- Answer satisfaction
- Helpful-answer rate
- Repeat usage
- Conversation completion
- Document/RAG success rate
- Agent task success rate
- Error rate
- Average latency
- Cost per active user
- Most requested features
