# DJ Foundation Model Track

This directory is the starting point for a future proprietary DJ model.

Planned pipeline:
1. License and provenance checks
2. Collection and filtering
3. Deduplication
4. PII/secrets removal
5. Quality scoring
6. Train/validation/test split
7. Tokenizer experiments
8. Small-model experiments
9. Instruction/post-training data
10. Benchmark and safety evaluation
11. Scale only after smaller experiments prove the recipe

Do not place raw third-party datasets, credentials or proprietary customer data in this repository.
