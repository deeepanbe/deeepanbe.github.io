# DJ AI Learning Loop

DJ AI should improve from measured outcomes, not blindly rewrite itself.

**Observe → Evaluate → Record → Identify recurring failures → Update prompts/tools/data → Re-evaluate**

Record:
- task type
- repository technology
- model/provider
- context selected
- patch outcome
- validation/test outcome
- reviewer feedback
- rollback/failure reason

Promotion rule:
A new prompt, tool policy, dataset version or model is promoted only when it improves the evaluation suite without unacceptable security/regression failures.
