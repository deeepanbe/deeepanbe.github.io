# DJ AI Assistant

The AI layer includes:

- Floating launcher on the main portfolio
- Drawer-based copilot experience
- Full workspace under `/dj/`
- Modes for chat, SQL, Python, Excel, DAX, dashboard recommendations, data cleaning, and resume fit
- Streaming-style local fallback responses
- Markdown and code block rendering
- Chat history stored in browser local storage

Backend integration is designed around `DJ_CONFIG.BACKEND_URL`.
