# DJ Job Profile Automation

Compliant resume-to-job matching service.

## Supported flow
1. Upload resume text/PDF through the application layer.
2. Parse into a normalized profile.
3. Match against user-provided or authorized job-posting data.
4. Generate tailored resume/cover-letter suggestions.
5. For LinkedIn/Naukri, use official/partner APIs where authorized or manual-assist links/forms. No scraping, automated login, or auto-submit.

This package intentionally separates matching from application submission.
